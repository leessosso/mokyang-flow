# 2청년회 조장 운영

2청년회 조장(조장)과 목사를 위한 주간 운영 도구입니다. 조·조원 관리, 조장 모임 나눔 조편성, 예배 좌석 배치, 조원별 비공개 양육 보고, 조장 인수인계를 한곳에서 처리합니다.

## 요구 사항

- Node.js 20+
- npm

## 설치 및 실행

```bash
npm install
npx prisma migrate dev
npm run db:seed
npm run dev
```

브라우저에서 [http://localhost:43123](http://localhost:43123) 으로 접속합니다.

## 데모 계정

비밀번호는 모두 `demo1234` 입니다.

| 역할 | 이메일 | 설명 |
|------|--------|------|
| 목사 | `pastor@church.demo` | 전체 조·양육 보고·인수인계 |
| 1조 조장 | `leader1@church.demo` | 1조 담당 |
| 2조 조장 | `leader2@church.demo` | 2조 담당 |
| 3조 조장 | `leader3@church.demo` | 3조 담당 (이전 조장 이력 포함) |

시드 데이터에는 3개 조, 10명 조원, 샘플 조장 모임·나눔 조편성, 예배 좌석, 김민수(1조) 양육 스레드가 포함됩니다.

## 주요 기능

- **조·조원**: 목사가 조를 만들고 조원을 배정합니다. 조장은 `내 조`에서 조원을 추가할 수 있습니다.
- **나눔 조편성**: `조장 모임` 상세에서 본조 고정 또는 임시 섞기, 자동 균형 배치, 드래그로 수동 조정.
- **예배 좌석**: 조별 구역 배치, 인쇄용 화면(`/worship/[id]/print`).
- **양육 보고**: 조장이 조원을 선택하면 목사와만 보는 1:1 스레드가 열립니다. 다른 조장은 볼 수 없습니다.
- **조장 인수인계**: 목사가 `조장 인수인계`에서 새 조장을 임명하면 이력이 남고, 조원·기존 양육 스레드는 조원 기준으로 유지되어 새 조장이 계속 열람·작성할 수 있습니다.

## 데모 시나리오

### 1. 양육 보고 (조장 → 목사)

1. `leader1@church.demo` 로 로그인
2. **내 조** 또는 **양육 보고** → **김민수** 선택
3. 새 메시지 작성 후 전송
4. 로그아웃 후 `pastor@church.demo` 로 로그인
5. **양육 보고** → 김민수 스레드에서 답장

### 2. 나눔 조편성

1. 목사 또는 조장으로 **조장 모임** → `3월 1주 조장 모임` 상세
2. 기존 조편성 확인 또는 새 날짜로 조편성 생성
3. **자동 균형 배치** 후 드래그로 조원 이동

### 3. 예배 좌석

1. **예배 좌석** → `주일 2부 예배` 상세
2. 조별 구역 변경 후 **인쇄용 보기** 확인

### 4. 조장 인수인계

1. `pastor@church.demo` → **조장 인수인계**
2. 1조의 새 조장으로 `최신조장(leader3)` 선택 후 실행
3. `leader3@church.demo` 로 로그인 → **양육 보고**에서 1조 조원(김민수 등) 스레드 확인

## 기술 스택

- Next.js (App Router), TypeScript, Tailwind CSS
- NextAuth (이메일·비밀번호)
- Prisma 7 + SQLite (`dev.db`)

## 환경 변수

`.env` 예시:

```
DATABASE_URL="file:./dev.db"
AUTH_SECRET="로컬 개발용 시크릿"
```

프로덕션 배포 시 `AUTH_SECRET` 을 반드시 변경하세요.
